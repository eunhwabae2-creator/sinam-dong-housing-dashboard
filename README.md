# 동대구역 인근 아파트 데이터보드

해움부동산중개용 대구 동구 동대구역 생활권 아파트 대시보드입니다. 지역 선택에서 동대구역 인근과 신암1~5동을 바꿔 볼 수 있습니다.

## 구성

- `index.html`: GitHub Pages 공개 화면
- `sinam-dong-housing-dashboard.html`: 편집용 원본
- `haeum-real-estate-logo.jpg`: 해움부동산중개 로고

가격·지수·TOP 10은 화면 구성용 예시이며 공식 실거래 API와 연결된 실제 시세가 아닙니다. 입지 분석 링크는 학교 통학구역, 도시철도, KTX 및 DGTX 계획을 별도로 확인하기 위한 참고 자료입니다.
